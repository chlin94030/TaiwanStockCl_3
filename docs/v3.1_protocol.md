# v3.1 研究：綜合模型再精進（預先宣告，寫於看任何結果之前，2026-11-13）

基準＝v3.0（短中長線都用名次加權）。五種換股日、開發期 2021 至盲測起點；母池同 v3.0（短線 BLEND500、中線 BLEND500／ADV500／MCAP300、長線 MCAP500）。

## 候選
1. **H1 殘差動能 5%**（v3.0 F1 單獨通過、與名次加權一起用 15% 時回撤深 3.1 → 這次測較小比例）：95% 原權重＋5% F1。
2. **H2 殘差動能 10%**：90%＋10%。
3. **H3 策略自身趨勢濾網（風險型）**：每個換股日，若「模型本身」（未調整版）的淨值低於自己近 120 個交易日均線 → 個股部位 70%、30% 放 0050；
   否則 100%。想法：動能策略在自己表現轉弱時常是動能反轉期（2022、2024-07、2026-07），減碼可降低回撤。參數固定、不調。
4. **H4 名次加權的穩健性（描述性）**：在其他母池（短線 ADV500、中線 MCAP500、長線 BLEND500）比較等權與名次加權，只報告。

## 採用門檻
* 報酬型（H1、H2）：與 v1.9 相同——中線三母池平均開發期超額 ≥ +1.5 個百分點且資訊比率不降；短線、長線各不下降超過 1 個百分點；
  中線開發期最大回撤不深於基準 2 個百分點以上（v2.4）。
* 風險型（H3）：中線開發期最大回撤改善 ≥ 2 個百分點、中線超額下降 ≤ 1 個百分點、資訊比率不降；短線、長線超額各不下降超過 1 個百分點。
* H1、H2 都通過時採用中線開發期超額較高者；H3 與 H1／H2 都通過時，再測兩者合併，合併也要通過全部門檻才同時採用。
* 盲測期、成本加倍、逐年只報告。

### 補充（看到 H1～H3 結果後、執行之前寫下，2026-11-13）
H1（5%）中線 +1.4、差門檻 0.1；H2（10%）中線 +2.4、資訊比率 +0.024，但回撤深 2.18 個百分點、超過護欄 0.18；H3 回撤反而更深。
動能組合常見的降回撤做法是依波動調整部位（波動大的股票少放），因此加測：
* **H5 名次加權 × 波動倒數**：每檔資金 ∝（名次權重 1.5→0.5）÷ 近 60 日波動，單檔上限 2/K（不加因子）。
* **H6＝H5＋H2**（殘差動能 10%）。
門檻同上（報酬型）。H5、H6 都通過時採用中線開發期超額較高者。這是 v3.1 最後一輪，不再追加候選。

### 結論
* **主模型維持 v3.0**（沒有候選通過預先宣告的門檻；最接近的 H1、H2 分別差 0.1 與 0.2 個百分點，依規則不放寬）。
  殘差動能已連續兩次「單獨看有效、但會讓回撤變深」，列入觀察。
* H5 把同一份名單改成「波動大的股票少放」，回撤明顯變小（中線少 6.7、短線少 7.4 個百分點），但報酬也少 4～5 個百分點，
  不符合報酬型或風險型門檻 → 不改預設，改成「資金配置」頁的選項（名次×波動：回撤較小），讓在意帳面起伏的人自行選擇。
* H3（模型自己轉弱時減碼）在歷史上反而更差：動能策略轉弱後常接著反彈，減碼錯過反彈。
