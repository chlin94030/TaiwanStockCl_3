# v1.7 十面向研究：預先宣告協議（寫於任何新候選績效被計算之前）

時間：2026-10-28（台北）。資料：台股 2017-01～2026-10-22；國際 2016-12～2026-10-23/26
（費城半導體 SOX、那斯達克 IXIC、VIX、日經 N225、韓國 KOSPI、美元兌台幣、台積電 ADR TSM；Yahoo Finance 日收盤）。

## 時間對齊（避免偷看未來）
* 訊號在台股收盤後（23:10 研究）產生、隔日開盤成交。
* 美股（SOX/IXIC/VIX/TSM）與匯率：只用「美國日期 ≤ T−1」的收盤（T 日晚上的美股在台北凌晨才收盤，研究時尚未發生）。
* 日韓（N225/KS11）：用 T 日收盤（14:30 前收盤，早於研究時間）。
* 「隔夜美股衝擊」執行規則（D2）：用美國日期 T 的收盤，於 T+1 台股開盤前已知，只影響進場時點、不影響選股。

## 十個面向與候選（固定）
| # | 面向 | 候選 |
|---|---|---|
| D1 | 美股連動：市場擇時 | SOX 低於 100 日均線 → 個股部位 50%、其餘現金；VIX>30 → 個股 50% |
| D2 | 美股隔夜衝擊：進場時點 | 訊號後美股 SOX 單日 ≤ −2.5% 或 ≥ +2.5% → 新買進改在當天收盤（不在開盤追殺／追高） |
| D3 | 美股連動：個股因子 | g_us_lead＝個股對前一夜 SOX 的 120 日 β × SOX 20 日報酬；g_us_beta＝β 本身 |

| D6 | 產業鏈輪動 | t_ind_mom＝同族群（產業鏈＋上中下游）其他成分股 60 日平均報酬；同族群最多 3 檔 |

## 評估與採用規則
* 只用開發期（2021-01-13～2025-10-27）挑選；主看中線（BLEND500、MCAP300、ADV300 三母池平均），短線、長線分別用各自選定母池再檢查。
* 採用門檻：三母池平均開發期年化超額 ≥ +2pp **且** 資訊比率不下降；風控類（D1、D10）若超額下降，需最大回撤改善 ≥ 5pp 且超額下降 ≤ 2pp 才列為「選用設定」（預設關閉）。
* 通過者再看：盲測期（2025-10～2026-10）、未用期間 2019-20、封存 2018，任一窗口比現行差 > 5pp 則不採用。
* 未通過者照實報告，不進預設模型。

## 補充（2026-10-28，仍在任何候選績效計算之前寫下）
* 短線、長線的套用條件：中線通過採用門檻後，該期間在自己選定母池（短線 BLEND500、長線 MCAP500）的開發期超額報酬不下降，才套用到該期間。
* g_us_beta 先驗方向為 0（讓資料決定）；固定 15% 權重用法的正負號以中線三母池開發期平均 IC 的正負決定。
* 描述性分析（不做採用判斷）：美股隔夜各級漲跌後，台股隔日開盤跳空、開盤→收盤、隔兩日的平均表現；台股與前一夜費半/那斯達克的逐年相關係數與 β（回答「台股是否越來越受美股影響」）。
