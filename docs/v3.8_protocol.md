## 三、App 調整
* 個股診斷新增「📋 多檔對照」：貼上雜誌、投顧或朋友的名單（代號或名稱），一次列出短／中／長線判斷、族群題材、是否在反彈候選。
  週刊名單與模型重疊者才是兩邊都看好；只出現在週刊的，多半不在選股範圍或被風控排除。
