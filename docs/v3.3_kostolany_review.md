## 一、預先宣告（寫於看結果之前）
1. **K1 股票已付清（固執的投資者）15%**：k_paid（融資餘額占股本越低越好）以 85%／15% 疊加到三個期間；
   門檻同 v1.9＋v2.4（中線三母池平均開發期超額 ≥ +1.5pp 且資訊比率不降；短、長線不下降超過 1pp；中線回撤不深於 2pp）。
2. **K2 大盤「利多不漲／利空不跌」（描述性）**：利多日＝前一晚費半 ≥ +2%、台股當天沒漲（≤ 0）；利空日＝費半 ≤ −2%、台股當天沒跌（≥ 0）。
   之後 20／60 日大盤（市值前 300 等權）報酬，與全部日子比較。
3. **K3 大盤雞蛋階段的歷史表現（描述性）**：每個階段之後 20／60 日大盤報酬、模型的超額報酬。

### 補充（看到 K1～K3 結果後、執行之前寫下）
* K3 顯示大盤處於 B1（修正下跌初期）之後 60 日平均 −1.9%、上漲機率只有 37%，是唯一明顯偏弱的階段，與原著「B1 賣出」一致。
  因此加測 **K4：大盤 B1 時短中線新買進改為一半資金、另一半放 0050**（長線已有 A3／B1／B2 減碼，不變）。
  屬「風險型」：中線開發期最大回撤改善 ≥ 2pp、超額下降 ≤ 1pp、資訊比率不降，或報酬型門檻（超額 ≥ +1.5pp）。
* K2 依原著原文加條件檢查（描述性）：「長期上漲之後」（大盤在一年區間上 80%）的利多不漲、「長期下跌之後」（距高點 ≥ 10%）的利空不跌。

### 補充二（發現問題後、執行之前寫下）
檢查大盤階段時發現：2020-03（−29%）、2022-10（−32%）、2025-04（−29%）三次重挫都被判成 **B2（相隨下跌）**，從來沒有出現 **B3**——
原著的 B3＝「成交量很大、持股人數很低、Y 點最低」＝恐慌出清，應該買進；但本系統長線在 B2 只持股 40%，等於在最低點附近減碼，**與原著相反**。
* **K5 B3 判定修正**：大盤距一年高點 ≥ 15%，且（近 20 日 ≤ −8% 或站上季線的股票 ≤ 25%），且融資金額近 60 日減少 ≥ 10% → 判為 B3（覆蓋 B1／B2）。
  門檻只看長線（唯一依階段調整持股的期間）：長線開發期超額 ≥ +1 個百分點、資訊比率不降、回撤不深於 2 個百分點；短中線不下降超過 1 個百分點。
  另報告新 B3 日之後 20／60 日大盤報酬。

* 模型因子與權重不變（K1、K4、K5 都未通過）。理由寫在儀表板「🥚 科斯托蘭尼」的原則對照表。
