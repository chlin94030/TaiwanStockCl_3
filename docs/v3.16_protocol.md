# v3.16 預先宣告：每日台股盤前日報（台北 07:00 前產出）——哪些內容可以標「已回測」

> 先寫規則、再看結果；結果附在「三、結果」。寫於 2026-11-19，看任何結果之前。
> 起因：使用者要求在儀表板加上每日盤前日報：美股收盤總評、夜盤趨勢、權值股動態、重大消息、影響台股關聯性、今日操作建議（保守／積極），
> 並與 v3.15 的模型精進併同大更新。
> 原則：日報是「資訊整理＋經過歷史驗證的規則」，不改選股模型。每一段都標證據等級；沒有通過下列檢驗的內容一律標「僅供參考・未回測」。

## 一、日報內容與資料來源

| 段落 | 內容 | 來源（盤前 05:40～06:40 抓取） |
|---|---|---|
| 美股收盤總評 | 道瓊、標普、那斯達克、費半、VIX、10 年債、美元、原油、黃金；一句總評（規則產生） | Yahoo Finance 日線 |
| 夜盤趨勢 | 台指期夜盤（期交所，連不到時略過）；台股收盤（13:30）後那指期、標普期的漲跌 | 期交所 MIS、Yahoo 分時 |
| 權值股動態 | 台積電、鴻海、聯發科、台達電、廣達、日月光、聯電、中華電、中信金、富邦金：昨收漲跌、外資買賣超；ADR 換算價與溢價；對應美股同業 | 研究資料、Yahoo |
| 重大消息 | 近 24 小時新聞標題（美股、台股、台積電、聯準會、輝達），依關鍵字標主題 | Google 新聞 RSS |
| 影響台股關聯性 | 預估今日大盤開盤跳空（含誤差帶）、台積電開盤預估、費半分級的歷史統計、美股同業大漲跌對應的台股族群 | 下列 M1～M4（每日研究重新估計） |
| 今日操作建議 | 保守型、積極型各 3～5 點；只用已回測的規則與模型名單 | 模型名單＋M3／M4＋v3.15 D1（0050 核心＋衛星） |

## 二、歷史驗證規則（訓練＝研究資料起點～2023-12；測試 2024-01～2026-10，測試期不參與估計）

* M1 預估大盤開盤：隔日「市值前 50 名市值加權開盤跳空」（加權指數的代理）對前一夜費半、那斯達克、台積電 ADR（換成台幣）、VIX 變化做線性迴歸。
  **測試期相關係數 ≥ 0.4，且預估 |跳空| ≥ 0.3% 的日子方向命中率 ≥ 65% → 標「已回測」**；否則「僅供參考」。
* M2 台積電開盤：2330 隔日開盤跳空對台積電 ADR（台幣計）報酬做迴歸；測試期相關係數 ≥ 0.4 → 「已回測」。
* M3 開高不追：測試期中 M1 預估跳空 ≥ +1% 的日子，大型股（市值前 300 等權）「開盤→收盤」平均 ≤ 0 → 「開盤不追價」列為已回測規則。
* M4 大跌不恐慌：測試期中 M1 預估跳空 ≤ −1% 的日子，大型股「開盤→收盤」平均 ≥ 0 → 「不在開盤恐慌賣出」列為已回測規則。
* 夜盤（台指期夜盤、那指期收盤後漲跌）研究資料沒有歷史分時 → 一律「僅供參考」。
* 新聞標題、主題標籤 → 「僅供參考」。
* 每天的預估與實際開盤會記在日報歷史（`morning_hist.json`），模型驗證頁顯示前瞻命中率；之後的資料才是真正的檢驗。
