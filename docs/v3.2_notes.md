# v3.2 輝達失分、誰補位？AI 晶片陣營輪動（2026-11-13）

使用者問題：輝達重挫拖累台股供應鏈，但競爭者（AMD、博通／Google TPU 等 ASIC）有更大空間，另一條供應鏈受惠——模型有沒有納入？

## 1. 台灣 AI 供應鏈的陣營重疊（kosto/supply.py CAMPS）
* 輝達陣營 12 檔、AMD 陣營 14 檔、ASIC 陣營 14 檔代表股（市場常見分類）。
* **8 檔同時在兩個以上陣營**：台積電、日月光投控、欣興、台光電、金像電、緯創、緯穎、英業達 → 輝達與競爭者此消彼長時「一進一出」。
* 只在單一陣營：
  - 輝達：鴻海、廣達、奇鋐、雙鴻、台達電、川湖、健策、富世達、高力（整櫃、水冷、電源櫃、滑軌）；
  - AMD：力成、南電、華通、勤誠、嘉澤、貿聯-KY、技嘉；
  - ASIC：世芯-KY、創意、聯發科、京元電子、旺矽、穎崴、致茂、智邦（設計服務、TPU、測試、雲端交換器）。

## 3. 模型有沒有納入？
* 選股模型不讀新聞、也不直接用「陣營」：它用動能、營收等因子，**陣營輪動會在 1～2 季內反映到名單**：
  中線名單平均每期有幾檔在各陣營——2025Q4 輝達 2.1 檔、ASIC 1.2 檔；2026Q1 輝達 0.6、ASIC 1.4；2026Q2 輝達 0.1、ASIC 1.0。
* 不新增「陣營輪動因子」的理由：
  1. 台廠多數同時供應三個陣營，可區分的只有約 24 檔，因子很稀疏；
  2. 歷史上真正分化的競爭者事件只有 1 次，無法驗證；
  3. 用美股同業做連動因子已測過兩次未通過（v1.7 國際連動 −1.6～−10.6 個百分點、v2.1 同業連動）；
  4. 研究資料庫沒有輝達、AMD、博通的個股歷史（每日更新的國際同業資料有，App 會顯示）。
* 改成在「消息衝擊評估」與個股頁顯示陣營曝險與輪動，讓使用者在消息當下判斷；
  資料庫累積更多競爭者事件（2026-11-10、11-13 等會自動納入）後，再以預先宣告研究檢驗。
