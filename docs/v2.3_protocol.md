# v2.3 研究：限空／禁空令、空單集中個股、美股與期貨的領先意義、因子權重平衡（預先宣告，寫於看任何結果之前，2026-11-09）

背景：金管會 2026-11-06 宣布、11-09 起實施限空措施（盤中借券賣出上限由 30% 降為 3%、融券保證金成數 90%→130%、放寬擔保品），
與 2025-04-07 的措施相同。加權指數 11/06 收 39,701.64，一週跌 12%。
使用者的問題：(1) 禁空令對大盤、對不同個股的影響；被空單狙擊的個股禁空後是否較容易止穩；(2) 美股期貨、台指期夜盤的領先意義；
(3) 綜合歷次想法重新檢視模型，各因子權重是否平衡，不要往單一方向偏離。
原則（與 v1.9 以來相同）：以歷史資料驗證為準；主模型只在預先宣告的門檻通過時才調整；其餘做成資訊顯示。不因為使用者的意見而放寬門檻。

## A. 限空／禁空令事件研究（描述性）
資料：研究資料庫（2017-01 至 2026-10-22）中的三次措施：2020-03-20（禁空＋國安基金）、2022-10-21（跌 3.5% 隔日平盤下不得放空）、
2025-04-07（與 2026 相同的三項限空措施＋國安基金 4/8 進場）。2026-11-09 這次還沒有之後的資料。
1. 大盤：措施生效前一日收盤起，之後 1／5／20／60 日加權指數報酬；與 v2.2「急跌事件」（同樣回落 ≥15% 但沒有限空）的平均相比。
2. 個股：成交金額前 500 名，依生效前一日的
   * 券資比（融券餘額／融資餘額）、
   * 融券餘額占流通股數、
   * 前 10 日融券增加（占 20 日均量）——「被空單狙擊」的代理，
   分五組，比較之後 5／20／60 日的超額報酬（減同期 500 檔等權平均）；並用迴歸控制前 20 日跌幅與市值（空單多的股票常常也是跌最多的）。
   限制：資料庫只有融券，沒有借券賣出餘額（2025、2026 的限空主要針對借券）；只有 3 次事件，只當量級參考。

   不做選股因子測試。

## C. 候選模型調整（套用 v1.9 門檻）
現況（11/05 研究）：中線權重 技術面 T 約 57%、基本面 F 約 43%，籌碼 C 與科斯托蘭尼 K 為 0（只保留 M 頭排除與長線水位等規則）。
* D1 技術面上限：每期權重中 T 家族絕對值占比 > 45% 時縮到 45%，差額依比例分給其他因子。
* D2 加入籌碼：85% 原權重＋15% 籌碼組合（開發期 IC 絕對值最大的 3 個籌碼因子，依開發期 IC 方向等權）。
* S1 空單因子：85% 原權重＋15% 券資比（方向依開發期 IC）。
* S2 只在急跌狀態加入空單：v2.2 定義的急跌狀態（0050 近 20 日 ≤ −8% 或距 120 日高 ≥ 12%）時，85% 原權重＋15% 券資比；其餘時間不變。
* 評估：五種換股日、開發期（2021 至盲測起點）、短線 BLEND500、中線 BLEND500／ADV500／MCAP300、長線 MCAP500。
* 採用門檻（報酬型，D2、S1、S2）：中線三母池平均開發期年化超額 ≥ +1.5 個百分點且資訊比率不降，短線、長線各不下降超過 1 個百分點。
* 採用門檻（平衡型，D1）：中線三母池平均最大回撤改善 ≥ 2 個百分點且年化超額下降 ≤ 1 個百分點；短線、長線年化超額各不下降超過 1 個百分點。
* 盲測期只報告。

### D. 權重平衡與急跌時的因子表現

* 每次權重重估的家族占比幾乎不變：短線／中線 T 48%（其中動能三因子 41%）、F 52%、籌碼與科斯托蘭尼 0%；長線 T 55～61%（全部是動能）、F 39～45%。
  最大單一因子：中線 t_rs120 19%、長線 t_rs120 31%。→ **模型沒有隨著時間往某一邊偏移**；最大的集中是「動能」，這是近期回落較深的原因。
* 中線因子在急跌狀態（48 個換股日）與一般時期的平均 IC：

| 因子 | 一般 | 急跌 | | 因子 | 一般 | 急跌 |
|---|---|---|---|---|---|---|
| t_high252 一年新高 | +0.059 | −0.048 | | f_rev_accel 營收加速 | +0.038 | +0.071 |
| t_lowidio 低特異波動 | +0.054 | −0.048 | | f_rev_rel 營收優於同業 | +0.011 | +0.055 |
| t_rs120 相對強度 | +0.007 | −0.013 | | f_rev_yoy3 近 3 月營收年增 | +0.017 | +0.047 |
| t_mom120x20 | +0.011 | +0.033 | | f_rev_streak 營收連續成長 | +0.021 | +0.043 |
| f_ep 盈餘殖利率 | +0.056 | −0.033 | | f_dy 殖利率 | +0.073 | −0.036 |

  急跌時「接近新高、低波動、高殖利率」失效，「營收動能」更有效；這正是 B1（急跌時動能減半）想利用的現象，但 B1 在開發期只多 0.6 個百分點、未達門檻 → 不改。
* 逐年 IC（中線）：t_rs120 2019–2022 為負、2023 起轉正；f_ep、f_dy 2025–26 明顯轉弱（+0.01～+0.02，2023–24 為 +0.10）；營收類因子 2025–26 最強。
  沒有任何一個家族的權重因此大幅改變（每次重估都用到當時為止的全部歷史並向先驗收縮），符合「不追最近行情」的設計。
